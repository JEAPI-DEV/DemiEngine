# Alpine demonstration source assets

Powered by Poly Haven. These assets are CC0-1.0 and may be redistributed,
including with this repository. Each imported source directory contains its
license and provenance record.

- Mountainside: https://polyhaven.com/a/mountainside — Dario Barresi and Rico Cilliers.
- Grass patch and distant cards: derived from https://polyhaven.com/a/grass_medium_01 — Rob Tuytel and Rico Cilliers.

The cliff's reduction recipe is authored in its asset manifest; rebuild its
ignored generated LODs through the native asset pipeline. The grass patch is a
Blender assembly of scanned plant variants. Its distant model uses three crossed
alpha-tested cards (six triangles), baked from the same patch. The reproducible
Blender preparation is `scripts/art/prepare_alpine_grass.py`.

No Poly Haven website thumbnails or example renders are redistributed here.
